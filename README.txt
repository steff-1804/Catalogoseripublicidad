SERIPUBLICIDAD - CATÁLOGO WEB
=============================

Este proyecto contiene:
- Logo extraído del material suministrado.
- Productos y precios transcritos del catálogo proporcionado.
- Filtros por categoría.
- Buscador.
- Selección de varios productos para cotización.
- Envío de la solicitud por WhatsApp.
- Galería con las láminas originales.

PUBLICAR EN GITHUB PAGES
1. Crea un repositorio nuevo.
2. Sube index.html, styles.css, script.js y la carpeta assets.
3. Settings > Pages.
4. Source: Deploy from a branch.
5. Branch: main / root.
6. Guardar.

NOTA
Los precios se dejaron tal como aparecen en las imágenes suministradas.
